LANGUAGE DETECTIVE: BOILERPLATE (starter) FILES

What is in this folder
- detective_starter.py : your starter code. Fill in every TODO.
- samples.py           : one training paragraph for each of the 7 languages (UTF-8 text). You can add a language.
- detective_app.py     : the web page for step 8. It uses your finished starter.
- requirements.txt     : the packages you need for the web page (gradio and a recent jinja2).

Setup
1. You need Python 3.10 or newer.  Check:  python --version   (Windows: py --version)
2. Steps 1 to 7 need nothing to install.
3. For step 8 (the web page) install the packages once:
     pip install -r requirements.txt
4. Open the files in an editor that saves UTF-8 (IDLE, VS Code, PyCharm and Notepad all do). samples.py has Hindi and accented letters.

Run
- The starter:   python detective_starter.py     (Windows: py detective_starter.py)
- The web page:  python detective_app.py         then open http://127.0.0.1:7860
Keep all the files in the same folder and run the commands from that folder.
Do not add share=True to the web page: it makes a public link to your computer.
